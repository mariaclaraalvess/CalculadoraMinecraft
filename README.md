# Calculadora de Recursos Minecraft 🧱

Uma ferramenta desenvolvida em Python para calcular a quantidade de blocos necessários para construir estruturas ocas no Minecraft, considerando paredes, chão e teto.

## Sobre o projeto

A Calculadora de Recursos Minecraft é uma aplicação desenvolvida em Python com o objetivo de auxiliar jogadores no planejamento de construções dentro do jogo.

## Funcionalidades

- Solicita o tipo de construção.
- Recebe largura, altura e comprimento.
- Calcula a quantidade de blocos considerando o espaço interno vazio.
- Converte os blocos em packs de 64 unidades.
- Informa a quantidade de blocos avulsos.
- Permite realizar vários cálculos sem reiniciar o programa.
- Possui tratamento de erros para entradas inválidas.

## Tecnologias utilizadas 🛠️

-Versão mais recente do Python.

## Como funciona?

O programa calcula o volume externo da construção e subtrai o espaço interno vazio.

Dessa forma, considera uma estrutura retangular oca, com paredes, chão e teto de uma camada de espessura.

## Como executar

1. Instale a versão mais recente do Python.
2. Faça o download ou clone este repositório.
3. Abra a pasta do projeto no terminal.
4. Execute:

```bash
python calculadora_minecraft.py
```
